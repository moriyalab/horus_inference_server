# horus_inference_server

## Introduction

`horus_inference_server`はゼロショット物体追跡を長時間の動画に適用するためのプロジェクトです。

このリポジトリにはゼロショット追跡+データベースが一体となったWebUIと出力されたデータを分析するツールがまとめられています。
